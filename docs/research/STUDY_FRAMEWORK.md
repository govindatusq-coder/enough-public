# Study framework

**Now set up in the app** (off until switched on): see PROTOCOL.md, RUNBOOK.md, PARTICIPANT_INFORMATION_AND_CONSENT.md, RECRUITMENT.md, ANALYSIS_PLAN.md and ETHICS.md. The notes below are the original framework.

Goal: test whether Load Bear reduces administrative effort and perceived household cognitive labour, not
just whether it extracts tasks accurately.

- **Design:** within-person pre/post (4 weeks usual practice, 6 weeks with Load Bear), ideally with a
  waitlist control. Ethics approval required before recruiting.
- **Behavioural measures (instrumented, consented):** see DATA_DICTIONARY.md.
- **Self-report (candidate validated instruments; check licensing and validation for this population):**
  NASA-TLX (workload), a household cognitive labour measure (e.g. Daminger's framework operationalised,
  or published cognitive household labour scales), Work–Family Conflict Scale (Netemeyer et al., 1996),
  System Usability Scale (SUS), Trust in Automation (Jian et al., 2000), a notification burden item set.
  No psychometric properties are claimed for any purpose-built items.
- **Outcomes:** administrative minutes per week (diary sample), perceived cognitive labour, work–family
  conflict, completion of time-sensitive obligations, satisfaction, trust, notification burden, retention.
- **Analysis plan:** pre-registered; mixed models with participant random effects.
