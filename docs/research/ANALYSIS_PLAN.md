# Analysis plan (pre-register before looking at outcome data)

- **Primary outcome:** raw NASA-TLX (mean of six items, 0–100) at week 6 minus baseline. Report the mean change
  with a 95% CI (paired t or bootstrap; n is small, so emphasise estimates and intervals over p-values).
- **Secondary:** admin minutes per week (weekly series; mixed model with participant random intercepts and week as a
  fixed effect); things that slipped per week; mental-load rating; reminder burden; SUS at week 6 (benchmark 68);
  trust item; share of admin carried (baseline vs end).
- **Engagement (behavioural):** captures per week, proportion set up without manual correction, verified outcomes,
  unwanted reminders, unresolved past-due items, operations Bear carried (Responsibility Transferred).
- **Missing data:** report completion per wave; analyse available cases; sensitivity analysis with last observation
  carried forward is not recommended; prefer mixed models that use all available weeks.
- **Reporting:** number invited, enrolled, completed, withdrawn (with or without deletion); no individual-level
  data in reports; describe as a pilot without a control group.
- **What would change the plan:** if TLX does not move but admin minutes fall, or vice versa, investigate with exit
  interviews before scaling; if SUS < 68, fix usability first.
