# Homepage idea photography

The four ENOUGH homepage examples show movement paired with an existing part of the day: returning a library book, waiting for an upload, dinner baking and a television ad break. Each illustration was created with the built-in image generation tool, inspected for matching actions, and optimised as WebP for the existing homepage card layout. These are illustrative scenes, not photographs or testimonials from users.
